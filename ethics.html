Digital Ethics & Attribution

This page explains the ethical considerations I followed while creating my personal portfolio website.

As an Information Technology student, I learned that creating a website also requires responsibility when using content, handling information, and designing for different users.

Copyright and Attribution

The website was created using HTML, CSS, and JavaScript. The layout and content were prepared for my Web and Multimedia Systems activity.

This website does not use third-party images. The design mainly uses HTML and CSS, including simple colors, spacing, and text.

Common system fonts are used instead of downloading external fonts.

Privacy

Privacy is important when creating a website. This portfolio does not intentionally collect or sell visitors' personal information.

The contact form is only a demonstration. The information entered in the form is not saved in a database or stored online in this version of the website.

Accessibility

I used clear headings, readable text, simple navigation, and labels for the contact form.

I also tried to keep the website simple so that users can easily understand and navigate the different pages.

If images are added in the future, descriptive alt text should be included to help users who use screen readers.

Website Security

When this website is published online, it should use HTTPS to help provide a secure connection for visitors.

I will also check that the website files use HTTPS when the website is deployed to avoid mixed-content problems.

Responsible Technology

Technology should be created and used responsibly. Developers should respect copyright, privacy, accessibility, and the rights of other people.

As an IT student, I will continue learning how to create websites and other technologies in a responsible way.
